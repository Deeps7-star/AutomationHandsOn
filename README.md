# Selenium Practice Project

A Selenium automation testing project created for practicing web automation using Java.

## Technologies

- Java
- Selenium WebDriver
- TestNG
- Maven
- IntelliJ IDEA

## Project Structure

The project contains Selenium practice scenarios covering different web automation concepts.

## Running the Tests

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Allow Maven to download the required dependencies.
4. Run the desired TestNG test.
